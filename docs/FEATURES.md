# 完整功能目录

对应测试版本：`0.4.0-r18-261120-1044-protected`。本页按现有实现归纳，功能入口、环境就绪和实际效果分别描述。

## 对话、协作与日常功能

### AI 聊天与模型配置

- **多服务商、多模型**：支持 OpenAI 兼容 Chat Completions、Anthropic、Google Gemini 与 Ollama 接口。可获取模型列表或手动添加模型，按服务商设置地址、密钥、自定义请求头和代理。
- **独立模型参数**：每个模型可以设置思考强度或预算、温度、历史轮数、上下文窗口、回答长度和自动压缩阈值；也可批量编辑模型。具体参数是否生效取决于所选接口和模型的实际能力。
- **流式对话**：正文、模型返回的思考与工具运行状态分别展示；支持取消、复制、选词复制、重新生成和回退。运行中可以补充文字到消息队列，或用引导消息调整当前任务。
- **聊天与项目会话**：既能自由聊天，也能为目标应用建立项目和多个独立对话。可以在对话里选择目标软件，工作区和项目上下文按会话关联管理。
- **图片与媒体消息**：可以添加图片供支持视觉输入的模型分析，查看工具截图、标注图和生成图，播放语音与视频附件。当前每条用户消息最多两张图片；图片识别能力取决于模型。
- **提示词与身份**：自定义系统提示词模板、群聊总提示词、AI 成员提示词；可调整聊天中 AI 与用户的显示名称、头像。聊天身份显示设置与实际模型提示词分别管理。

### 设置与提示词入口

- 设置页顶部提供搜索，可按名称或关键词直达相关设置。
- 聊天的模型选择面板内提供“模型设置”；提示词选择菜单内提供“添加 / 管理提示词”，悬浮聊天也可跳转。返回聊天后刷新模型与模板列表。
- “设置 → 提示词 → 破甲”是可选内置提示词开关，默认关闭；开启后与现有模板、成员提示词及必读技能共同作用，不替换自定义提示词。
- 默认系统提示词正文为空，原内置工具引导由自动加载的必读内置 Skill 提供。保留已编辑的提示词，并在保留 ID 冲突时迁移自定义技能及其绑定。
- 模型/提示词保存工作使用串行后台队列，模型编辑采用防抖、按 ID 合并和保存失败保留草稿；实际流畅度需要在设备上验证。

### 多 AI 成员与任务协作

- 一个对话可配置 **1–6 位 AI 成员**。每位成员可以选择不同服务商、模型、提示词、头像、独立参数和工具权限；人员预设可保存后邀请到其他对话。
- 提供自然对话、讨论后操作，以及普通协作、各自调研后讨论、边指导边执行、角色扮演等工作流设置。可使用智能参与、仅 `@` 指定成员或依次参与，并设置发言与操作轮数上限。
- 普通协作的任务路径为 **共同讨论 → 结构化分工 → 独立任务并行 → 共同复盘**，最多三个成员同时执行。任务依赖与声明的独占资源影响调度，失败依赖向下游传播，取消后不自动重放已执行操作。
- 对实际向队友提出的问题安排有界回应，保留明确只让一位成员回答的选择。群聊精简显示工具状态，保留思考、成员回复和媒体产物，不在群消息里铺开完整工具参数与原始返回。
- 另有主助手内部的 **子代理协作**：按需委托独立任务，同时运行数可设为 1–3，继承主对话的模型参数、提示词、关键上下文、项目与工具开关，再把结果交给主助手汇总。

多成员与子代理会产生额外模型请求。并行不等于节省 token，也不等于所有屏幕、文件和执行器已经完全隔离；成员调度中的资源互斥依赖分工声明。协作质量仍取决于模型对任务与协议的理解。

### 本地记忆、笔记与世界书

- 手机本地保存并检索关键偏好、明确设定、重要约定与项目进展，保留原话、角色和出处。支持自动保留、跨会话回忆开关，以及搜索、查看出处、忘记片段、忘记对话、清空和重建索引。
- 项目结论和进度按工作区区分；长对话可以按预算补充当前场景、阶段、完成项和阻塞项，辅助继续对话。记忆检索采用本地关键词/全文索引，不需要外部记忆服务器或向量数据库。
- 手动记忆支持编辑、停用、置顶和指定当前对话或全部对话。
- 支持导入酒馆世界书 JSON，包括 `entries` 对象、数组及 `character_book`，可以编辑关键词与内容。正则、概率、深度位置等高级规则存在兼容范围，导入时显示说明。

关键记忆筛选与检索不能保证记住全部隐含信息或让任意模型始终保持角色。工具日志、推理、附件和凭据不会作为自动记忆正常索引内容。**当前不提供已停用的外部 Mem0 功能。**

### 语音输入、朗读与默认助手

- 支持中文实时语音输入，本地 Zipformer 识别模型就绪后可离线转文字；系统语音助手入口可以从 APK 准备内置识别资源。独立语音输入面板也保留模型准备入口。
- 可选下载 SenseVoiceSmall，对 30 秒以内短句做本地精确复核；也提供需要用户明确选择的 OpenAI 兼容转写服务。云端转写会上传录音到所选服务商。
- AI 回复可使用系统 TTS、兼容 `/audio/speech` 的在线服务或自定义 JSON 语音接口。支持自动朗读、情景语音表达、语言、音色、语速、音调与音量设置，语音消息可播放/暂停并展开文字。
- 可设为系统默认语音助手，通过系统提供的手势或按键唤起；使用当前模型、提示词和工具，并在独立对话保存语音任务。
- 提供可手动开启的本地“小灵”唤醒。熄屏监听需要持续使用麦克风与前台通知，会增加耗电；锁屏新指令仍需解锁，不自动解除系统锁屏，服务被系统关闭后需要重新开启。
- 已启用直接指令处理时，明确的音量、亮度、手电筒、应用启动和场景搜索可走本地指令路径；复杂或有歧义的任务继续交给 AI。设备权限仍按实际操作通道要求获取。

### 图片、视频创作与视频理解

- 支持配置 OpenAI Images、Gemini 图片生成接口，可按模型设置图像尺寸、质量、端点和优先生图模型。
- 支持 ComfyUI 图片/视频工作流：提交 API 格式工作流、查询任务状态、下载产物；需要用户已运行且可访问的 ComfyUI 服务、实际可用的模型与节点。
- 支持 OpenAI 风格视频任务接口及明确配置的异步 JSON 媒体网关，按服务商设置端点、请求模板、任务 ID、状态和媒体地址字段。
- 媒体任务保留任务记录与远端 ID，支持继续查询、显示进度和请求取消；未知提交结果不盲目重新生成。取消请求是否真正停止仍以远端状态为准。
- 可选择让 AI 根据聊天场景主动配图、语音表达或短视频，只使用用户已经配置并启用的服务。
- 视频分析可对当前工作区视频或可直接访问的视频链接抽取 1–8 帧，附时间标记交给视觉模型分析；**不包含音轨转写，也不等于完整连续视频理解**。本地视频大小上限为 256 MiB，解码取决于系统支持。

小灵提供客户端和任务管理，不包含通用本地生图/视频大模型，也不保证任意云厂商接口、ComfyUI 自定义节点或受登录/DRM 保护的视频网站都可用。模型服务、网络和解码兼容性需分别满足。

### 搜索、浏览器与场景扩展

- 联网搜索可选 Brave、Tavily、SearXNG、DuckDuckGo，多来源查询后合并重复链接，保留来源与失败状态；支持时间范围、包含/排除域名和超时设置。
- 提供内嵌浏览器的标签页、导航与网页交互入口，统一网络代理可用于模型、搜索、媒体与浏览器。
- 场景插件可按开关跳转浏览器、B 站、抖音搜索，显示短时悬浮提示或给出专注建议；专注建议不锁住其他应用。更复杂扩展可接入现有 Skills、MCP 与自定义工具入口。

联网来源需要网络与对应配置；部分搜索来源需要用户自己的密钥并可能计费，免费来源也可能限流。网站权限仍通过确认和系统权限处理。

### 主动提醒与通知

- 可按对话或全局开启饭点、睡前、喝水、久坐、连续用屏、电量、每日小结、重要通知等主动消息。
- 支持静默时段、每小时/每天频率、触发阈值和消息语气设置，可在应用外通过通知提醒。
- 重要通知功能需要系统通知使用权，只有用户选择的应用，其脱敏通知内容才会交给模型生成建议。

该功能依赖用户主动开启相关服务、通知权限及系统后台运行条件，不是保证准时送达的系统闹钟。持续未回应时，部分提醒会暂停。

### 手机控制、同屏协作与独立副屏

- 提供无障碍读屏、点击与输入入口，以及 Root、Shizuku / Sui 等按设备能力启用的操作通道。专用 AI 输入法需要用户在系统中启用并选中。
- **同屏协作**：用户与 AI 观察、操作同一个主屏页面，用户操作后 AI 可以重新观察并接续。
- **独立副屏**：在手机上创建另一个显示环境运行目标应用，查看预览，调整方向、尺寸/布局与显示刷新率，并在主屏与副屏之间交接应用任务。
- 支持点按、长按、滑动、双击、缩放和多指轨迹。执行绑定当前会话、目标和观察结果，取消时清理输入，不自动重放手势。
- 对话功能菜单中的 **界面分析** 使用截图、无障碍控件树和 OCR，支持缩放、平移、点选、搜索、复制控件文字/描述/ID/类名/坐标/选择器，以及把裁切图与证据加入聊天草稿。
- 浮动聊天窗可拖动、缩放、收起与返回主界面，悬浮入口显示任务状态并跳转相关对话。

同屏和独立副屏入口需要 Root 及相应授权；无障碍、悬浮窗和输入法通道需要各自权限。独立显示环境不保证与主屏页面相同，受保护画面或不支持多显示屏的应用可能无法显示。输入成功返回不等于目标界面效果已经验证。

### 外观与用量统计

- 暖色与纯黑主题、自定义颜色、字号、圆角、头像尺寸、气泡宽度、气泡/工具卡颜色与透明度、玻璃效果、本地图片/视频背景及页面外观设置。
- 新安装默认白色背景，设置界面采用适配浅色背景的配色；已有安装保留用户自己的外观。默认外观不导入开发者的聊天、自定义提示词或 API 配置。
- 记录服务端返回的 token 用量，可按供应商/模型填写单价，查看当前会话与模型累计费用。未知用量和未知价格分别标明，费用统计不包含服务商套餐、税费、汇率、工具费等额外项目。
