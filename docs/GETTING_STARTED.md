# 安装、配置与权限

## 安装包与升级

从本仓库 Releases 下载 `.apk` 与 `SHA256SUMS.txt`。文件约 882 MB，安装及离线工具解压还会使用额外空间。包名为 `com.aiagent.app`，Android 最低版本为 8.0/API 26；ARMv7 可以安装不代表完整 ARM64 工具环境可用。

同包名、同签名升级可覆盖安装并保留数据；系统提示签名不一致时不要直接卸载清数据，先核对安装包来源并备份。此版本保留既有 debug signingConfig 的证书身份，但 APK 为不可调试的 Release 构建。

## 先配置 AI，再按需准备工具

“AI 服务商与模型”中填写自己的地址与凭据，选择 OpenAI 兼容 Chat Completions、Anthropic、Gemini 或 Ollama。添加或获取模型列表，再设置每个模型的参数。接口兼容不表示任意代理网关都支持所有参数。

也可从聊天的模型选择面板点击“模型设置”，或从提示词菜单点击“添加 / 管理提示词”直接进入对应设置。设置页顶部支持搜索。

需要可选内置提示词时，在“设置 → 提示词”开启“破甲”；它默认关闭，开启后与已选模板及成员提示词共同作用。新设备默认白色背景，已有安装保留外观配置。

模型、语音云服务、图片/视频生成和部分搜索由所配置服务商处理，费用和隐私政策由该服务决定。小灵不附送开发者 API，不把开发者的私人提示词或聊天导入你的设备。

运行环境页面的一键准备会从 APK 准备内置工具和完整 CLI，不联网下载这些基础资源。首次解包耗时与设备性能、存储有关；逐项查看结果。后续自行安装的新软件、可选模型或访问远程服务可能需要网络。

## 自编译扫描模块的前提

先确认精确内核版本和厂商构建、ARM64 架构、页大小、内核源码/配置或可核验 ABI 证据、KPM 加载器、所需符号，以及 nofault、allocator、RCU、uaccess 的真实实现。另需 Python 3、支持 AArch64 的 Clang、ld.lld、本地可写目录与足够空间，以及重要数据备份和故障恢复路径。

在扫描或 RT 卡打开“适配前提与构建方法”，导出构建源码，在终端执行：

```sh
tar -xzf xiaoling-scan-build-source.tgz
python3 hmkpm/build.py --clang clang --linker ld.lld --name my_scan --version 1.1.0 --out out/my_scan.kpm
```

命令只构建，不自动加载。修改名称/版本不等于完成新内核适配；未支持的厂商内核需要有依据的 profile 和测试，不可只放宽白名单。导入后先检查声明，显式加载后再核对协议与身份。运行镜像哈希和实际扫描效果仍需分别验证。

RT 是独立驱动，以上扫描源码不能重建 RT。适配 RT 要有原驱动源码、许可、相应工具链及目标内核构建条件。
