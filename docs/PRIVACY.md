# 数据与隐私说明

## 发布包包含什么

本测试版携带程序代码、内置工具、产品所需提示与工具说明、许可证，以及预设外观资源。新设备默认白色背景；已有安装保留用户外观。可选的“破甲”内置产品提示词随程序提供，默认关闭；开启后会作为提示的一部分发送给所配置模型服务。

发布不包含开发者设备上的 API 凭据、私人提示词、聊天导出或整份应用配置。公开仓库与附件按单独清单准备，不上传开发工作备份、手机日志、签名私钥或 R8 mapping。

现有自动检查覆盖源码与 APK 的常见凭据模式、已知个人文件名和默认外观哈希。这不是对任意编码秘密或所有深层依赖内容的数学证明。

## 使用时数据可能去哪里

- 对话、图片、工具选定的上下文会根据你的操作发送给所配置模型服务商。
- 云端语音转写会发送录音；在线 TTS、图像与视频生成会发送对应输入。选择本地语音识别时，识别计算在设备端完成。
- 联网搜索、网页浏览、MCP、远端媒体服务和自定义工具会访问你配置或操作的服务。
- 本地记忆、工作区、聊天历史、工具产物与导入文件在手机本地保存；联网模型可能收到你启用的检索上下文。
- 重要通知建议只在启用并选择应用后处理相应通知；模型请求涉及的通知内容应按自身隐私需求配置。
- Root、框架、终端、网络捕获与内存工具能够接触敏感设备数据，是否调用由所选功能、授权和工具设置决定。

请在分享日志、截图、抓包、模块或工作区之前自行脱敏。问题反馈通常只需要版本、环境、操作步骤和相关错误，不需要完整账号配置或聊天历史。
