# 小灵 · Android AI 工作台

把 AI 对话、多人协作、手机操作、终端开发与应用分析放到一部手机里。

## 作者与项目支持

小灵由本人持续开发和维护。作者主页与项目支持：

https://afdian.com/a/xiaoling886?utm_source=copylink&utm_medium=link

小灵既可以用于日常聊天、语音、角色与世界书，也可以围绕一个目标应用建立项目，让 AI 调用手机本地工具，整理证据、编写脚本、检查界面、分析文件并协作完成任务。运行环境和已集成的大型工具随 APK 携带，按需在手机本机准备，日常工具执行不需要电脑后端。

**“工具内嵌”不等于“聊天大模型内嵌”。** 聊天、联网生图、视频生成等需要自行配置服务商、模型与 API；服务费用以所选服务商为准。

## 快速开始

1. 从 Release 下载 APK，核对 `SHA256SUMS.txt` 后安装。旧版升级使用相同签名覆盖安装，先备份重要资料。
2. 在“AI 服务商与模型”添加自己的 API 地址、密钥和模型，先测试普通对话。
3. 按需要启用无障碍、悬浮窗、输入法、语音、通知等权限；使用 Root 或框架功能时，再检查对应通道。
4. 需要终端或开发分析工具时，打开“运行环境 → 一键离线准备运行环境”，阅读说明并等待各组件结果。
5. 用目标应用建立项目，再选择对话成员和工具权限。KPM、RT、目标 Hook 和网络捕获需要在各自入口明确操作，不由离线准备自动开启。

## 最新更新

- 聊天底部取消模型和提示词旁的独立加号；在模型选择面板点击“模型设置”直达设置页，在提示词菜单点击“添加 / 管理提示词”直达提示词设置。
- 悬浮聊天补齐提示词设置入口，保留返回聊天后刷新模型与模板列表。
- “设置 → 提示词”新增默认关闭的“破甲”开关；开启后，内置提示词与现有模板及成员提示词共同作用。
- 设置顶部提供搜索直达；调整模型、提示词编辑的保存路径，新设备使用白色默认背景并适配浅色设置界面。
- 原默认系统提示词正文清空，工具引导改为自动加载的必读内置 Skill；保留已编辑的提示词，并处理与自定义 Skill 的 ID 冲突。
- RT 桥接改进进程身份与回执状态判断，避免把未写回计数当成零命中；已知 RT 零命中仍未解决。

## 使用前提与验证范围

普通聊天与部分文件功能不需要 Root；完整终端、同屏/副屏及部分动态分析需要各自的权限和设备环境。内置 APK 原生构建工具面向 ARM64、Android 11+、4 KiB 页，不能把整包宣传为全功能支持 16 KiB 页。

内核扫描的 `6.1 / 6.6 / 6.12` 是经过接口核对的候选范围，仍需匹配厂商内核、符号与兼容 KPM 加载器。Root 不等于具有 KPM 加载能力。通用构建流程不等于跨机型通用二进制；RT 需要原驱动相应材料，扫描源码不能生成 RT。

本次 1044 版已通过 Release 构建、签名、保护产物和分发隐私检查。此前 1014 提示词功能版本的 98 项相关 JVM 测试通过；1044 的聊天入口调整没有新增或重跑单元测试。1044 版尚未安装到手机，界面、卡顿和实际设备兼容性仍待实测；不宣称 RT 零命中或内核 Hook 效果已经验证解决。
